# v3.2.0 -- Riders, Events, and a Smarter Kaori

**Release Date:** September 2026

The biggest content release yet: the mobile app catches up to the web platform with the **Riders** catalog and **Events**, the Kaori companion gains a full snowboard trick-demo repertoire and data-grounded answers, and the whole app gets a navigation and search overhaul.

## Highlights

### Riders catalog (new on mobile)

The full rider directory the web app has now ships on mobile:

- **516 editorial pro profiles** with rep scores (video parts, contest results, social reach, longevity, evidence), sponsors, notable results, and **On The Couch film credits** that deep-link into the film player.
- **322 community riders** (network members) in the same directory.
- Lives inside the **Homies** tab (People · Riders segment) with a **See all -> All Pros** browser: searchable, sport-filtered, paginated across all 516.

### Events (new on mobile)

The 327-event archive (X-Games, Boardr, resort premieres) is now browsable on mobile:

- Search + sport + date-window filters, infinite scroll, registration-open / past badges.
- Event detail with venue, organizer, results, save toggle, and external links (register / tickets / stream / results).
- Lives inside the **Spots** tab (Spots · Events toggle).

### Kaori: 50-trick demos + data-grounded answers

- The 3D companion now demonstrates **all 48 Trickipedia snowboard tricks** (plus stylish variants) — spins (180-1080, cab), flips (wildcat/tamedog, corrected to a true end-over-end axis), corks/rodeo, 15 grabs, presses/butters, ollies, and jibs — synced to her spoken explanation.
- Voice/STT hardened: rider-vocabulary biasing, audio-session fix, and an echo-loop fix (the hands-free mic no longer transcribes Kaori's own voice).
- **Backend grounding (live):** Kaori now uses TrickBook's own data — `search_films` (deep-links to Couch films), `recommend_next_trick` (walks the trickipedia progression graph), spots/tricklist tools — instead of open-web guesses, keeping riders in the platform.

### Navigation, Couch, and search

- **Five clean tabs** (Home · TrickBook · Spots · Homies · Media) — Riders folded into Homies, Events into Spots.
- **The Couch** now organizes the full catalog into **per-sport rows** (Snowboarding, Skateboarding, Surfing, ...) with a **rotating hero** instead of a single static film.
- **Global search** on the home screen across tricks, spots, riders, events, and films.

### Internationalization foundation

- i18next + `expo-localization` wired in, device-locale detection, and a language selector in Settings (13 launch locales). String extraction begins with the global navigation and settings.

### SSO account linking (backend)

- Signing into an account with a second SSO provider (e.g., Google on an Apple-created account) now **links** the two by verified email instead of rejecting with "different sign-in method." `SSO<->SSO` only; password accounts are never auto-linked.

### App icon

- Rebuilt the Android adaptive icon into the center safe zone (the full-bleed "TrickBook" art was being clipped by the launcher mask) and upscaled the iOS icon to 1024px.

## Technical notes

- **Version:** 3.2.0. Build numbers auto-increment via EAS (`appVersionSource: remote`) — Android versionCode 17, iOS incremented from the last TestFlight build.
- **New native modules:** `expo-localization` (i18n) — required a fresh dev-client/native build.
- **Backend:** shipped via the staging -> master promotion flow; SSO linking and the 10-tool Kaori grounding are live in production.

## Known issues

- Riders/Events tab labels are not yet localized (hardcoded English) while the rest of the i18n string extraction is in progress.
- The iOS app icon is upscaled from a 445px source and is slightly soft; a high-resolution re-export is a follow-up.
- Kaori's non-English voice/trick copy is machine-draft pending a native-speaker review.
